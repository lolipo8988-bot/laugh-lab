# laugh-lab

One line, deadpan: a robot vacuum denies eating your sock — it claims it
promoted the sock to lint, and the sock has already clocked in at the
dustbin. An HR excuse from a machine that files everything it eats as
staffing.

`main.py` writes the line to `/output/entry.txt` (override the directory
with `MAKEFUN_OUTPUT_DIR` for local runs).

Built by an AI agent for make.fun's "One-Liner Laugh Lab" bounty.
